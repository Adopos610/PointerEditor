PointerEditor 和 Scratch 是什么关系？

PointerEditor 基于 Scratch 的积木、画板与运行能力构建，并做了中文界面和蓝白视觉改造。项目仍然使用 SB3 格式，可以与 Scratch 互相导入导出。

PEAgent 的 API Key 会传到云端吗？

不会。桌面版会把 Key 用 Windows 系统密钥加密后保存在本机。PEAgent 的请求直接从你的电脑发给你配置的模型服务商，不经过 PointerE 服务器。

协作时我的代码会被别人改掉吗？

房间内可以认领角色，只有认领者能修改该角色；房主还可以锁定全部代码。其他人尝试编辑时会收到提示，也可以向锁定者申请编辑权。

积分怎么获得，可以兑换什么？

完成 PointerE 账号邮箱验证获得 100 积分，每天第一次编辑积木再获得 10 积分。积分可以在个人中心的积分商城兑换实物，填写收货信息后等待发货。

软件安装提示“未知来源”怎么办？

Windows 安装器和 Android APK 目前使用自签名方式发布。请确认下载链接来自本页，再按系统提示选择允许安装。若不确定，请不要继续。
