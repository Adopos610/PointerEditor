你可能想知道的。

PointerE 账号和创客次元账号通用吗？

不通用。PointerE 是 PointerEditor 的协作账号，创客次元账号用于作品社区。两者分开管理，互不影响。

不登录可以创作吗？

可以。本地创作、导入导出和运行作品都不需要登录；在线协作和发布作品时才需要 PointerE 账号。

协作房间会被别人看到吗？

房间通过房间码加入，适合小范围协作。请不要把房间码公开发布；房主还可以随时锁定全部代码。

安装时提示“未知发布者”怎么办？

当前安装器暂未进行代码签名，Windows 可能会提示未知发布者。确认来源可信后，选择“仍要运行”即可。
