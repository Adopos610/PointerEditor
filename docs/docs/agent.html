PEAgent 使用指南

PEAgent 是 PointerEditor 内置的 AI 创作助手。它可以生成积木、创建变量和广播、插入脚本，也能直接绘制 SVG 角色造型。

第一次配置

  1. 点击顶部 PEAgent 打开面板，进入“设置”。
  2. 选择服务商：DeepSeek V4、OpenAI 或自定义兼容接口。
  3. 填写 API Key、Base URL 和模型名称。DeepSeek 的常用参数已经预填。
  4. 设置 Agent 权限，保存后开始对话。
API Key 只保存在本机

桌面版使用 Windows 系统密钥加密保存 Key，请求直接发送到你填写的模型接口，不经过 PointerE 服务器。网页版不支持本地 Key 调用。

模型选择

服务可用模型说明
DeepSeekdeepseek-flash / deepseek-v4-pro默认预填，支持深度思考；flash 支持图像理解
OpenAIGPT / o 系列等需要可访问的 OpenAI 兼容接口
自定义任意兼容模型支持 OpenAI Chat Completions 或 Anthropic 兼容格式

模型切换在对话页顶部的下拉框里完成，切换后会保存到本机配置。

输入区工具

  • 思考：开启深度思考，并可选择思考强度。思考模式下部分模型会忽略 Temperature。
  • 选择积木：把积木区当前选中的积木作为上下文加入对话。
  • 添加文件：附加文本或代码文件（最大 400KB，读取前 2 万字）。
  • 网页搜索：开启后先检索网络资料，再把结果交给模型。
  • Enter 发送 / Shift+Enter 换行：中文输入法组词时不会误发送。

权限模式

模式行为
操作前确认（推荐）回答结束后展示操作摘要，你确认后才执行
完全权限自动创建变量/广播、插入积木、添加 SVG 造型
只读建议只给建议，不修改作品

Agent 能做的操作包括创建变量和广播、插入 Scratch 积木、添加 SVG 角色造型；它不会执行任意 JavaScript。所有操作都会在本地校验后应用。

会话与导出

  • 左侧会保存最近的会话，支持切换、删除和自动标题。
  • 回答支持 Markdown、代码块和流式输出。
  • “导出会话”可以把当前对话保存为 Markdown 文件。
  • Agent 最小化后会留在顶部浮标，可以取消运行或重新打开。

常见问题

提示 401 / Authentication Fails

检查 API Key 是否完整、是否过期，以及服务商与 Base URL 是否匹配。Key 不要带空格或引号。

提示余额不足

AI API 费用由模型服务商按 token 计费，和 PointerEditor 本身无关。请在服务商控制台充值或换用其他模型。

回答很慢或中断

可以关闭深度思考、减少上下文，或检查网络。长回答会被 Max Tokens 和服务商能力限制。

自定义接口应该怎么填

Base URL 一般填到 /v1 或服务商给出的接口根路径；模型名称按服务商文档填写。切换服务商后可先用“保存并开始”测试。
