扩展商店

PointerEditor 的扩展商店是自有的全屏扩展页面，包含官方扩展、Pointer 精选、社区精选和自定义加载。安装扩展后，积木区会直接出现新的分类。

打开扩展商店

  • 在编辑器积木区左下角点击“添加扩展”图标。
  • 左侧选择分类，右侧搜索或浏览扩展卡片。
  • 点击“添加”，扩展会安装到当前作品，并自动回到积木区。
  • 也可以在浏览器访问 peditor.ctspace.xyz/extensions/ 查看扩展目录和安装地址。

分类说明

分类内容
官方扩展音乐、画笔、视频侦测、文字朗读、翻译、Makey Makey、micro:bit、LEGO 等内置扩展
Pointer 精选Pointer 工具箱、Pointer 数学工具，由 PointerEditor 官方维护
社区精选由社区作者维护的扩展，安装时从扩展作者的官方地址加载
自定义加载从网址、文件或 JavaScript 源码加载扩展；需要用户确认来源

Pointer 官方扩展

Pointer 工具箱

  • 当前日期、当前时间、当前星期、当前时间戳
  • 扩展运行秒数、重置计时、随机 UUID
  • 文本长度、反转文本、替换文本

Pointer 数学工具

  • 把数值限制在范围内、区间映射
  • 四舍五入保留小数、百分比
  • 随机整数、随机小数、千分位格式化、偶数判断

社区扩展

社区扩展由原作者维护，包括文件、运行时选项、指针、文本、本地存储、剪贴板、内嵌框架、3D、画笔、克隆、计时器、通知等。扩展商店会标注作者和分类；安装前请确认来源可信。

安装与使用

  1. 在扩展商店点击“添加”。扩展安装后不会出现单独的“启用”按钮，积木区会直接新增分类。
  2. 扩展会记录在作品文件里；重新打开作品时会自动加载。
  3. 如果想重置扩展，刷新或重新打开编辑器；已保存在作品里的扩展会在加载项目时恢复。
  4. 部分扩展需要摄像头、麦克风、网络或额外权限，首次使用时浏览器会询问。

自定义加载与安全

只加载可信扩展

扩展在浏览器中拥有接近编辑器的权限。不要加载来源不明的 JavaScript 或从未知短链接下载的扩展。PointerEditor 会对自定义来源进行确认，但最终仍需你判断。

  • 支持从网址加载扩展 JS。
  • 支持选择本地扩展文件。
  • 支持直接粘贴 JavaScript 源码（仅建议开发者使用）。
  • 扩展加载失败时，先检查网络、地址是否以 .js 结尾，以及是否被浏览器拦截。

开发者

Pointer 官方扩展源码在仓库的 scratch-gui/static/extensions 下。社区扩展遵循 Scratch extension API；如果你要编写自己的扩展，可以从一个最小的 getInfo 和积木定义开始，然后在本地加载测试。
