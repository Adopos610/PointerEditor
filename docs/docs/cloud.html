PointerE 协作与云服务

PointerE 是 PointerEditor 配套的协作账号系统，和创客次元账号相互独立。它负责登录、协作房间、角色认领、代码锁定、TODO 和积分。

账号体系

  • PointerE 账号用于编辑器在线协作，注册地址：vable.ctspace.xyz/register。
  • 创客次元账号用于作品社区和发布，两者不通用。
  • 注册需要图形验证码和邮箱验证；验证邮件由 PointerE 服务发送。

登录和开始协作

  1. 打开 PointerEditor，点击顶部“云端 → 在线协作”。
  2. 使用 PointerE 用户名或邮箱登录。
  3. 创建房间，或输入房间号加入已有房间。
  4. 邀请同伴进入同一房间，大家会看到同一份项目。

角色认领与代码锁定

  • 每位成员可以认领一个或多个角色，只有认领者能修改该角色的积木。
  • 其他人尝试修改被认领角色时，会看到锁定者，并可以发送编辑申请。
  • 房主可以锁定全部代码；锁定后只有房主能编辑。
  • 新增或删除角色时，由房主同步整个项目。

TODO 房间同步

项目 TODO 会随协作房间同步，作者和成员看到同一份清单。支持添加、勾选完成、删除和清除已完成；不联网时保存在本地。

多窗口与素材协作

  • 文件 → 新建窗口，可以同时打开多个编辑器窗口。
  • 角色卡片右上角 ↗ 可以直接拖到另一个窗口，角色会连同造型、声音和积木一起导入。
  • 协作同步以积木和角色为单位；跨窗口导入适合整理素材和拆分工作。

安全与连接

  • 协作服务使用 WSS（TLS）加密；自定义公网服务必须使用 wss:// 地址。
  • 服务端会校验 Origin、限制请求频率和消息大小，并对登录失败做限制。
  • 不要把 PointerE 密码、验证码或管理入口分享给其他人。

常见问题

登录提示账号或密码错误

确认使用的是 PointerE 账号，而不是创客次元账号；检查邮箱是否已验证、账号是否被停用。

加入房间后看不到别人的修改

确认双方在同一个房间、网络正常，并且对方没有修改未认领的角色。必要时重新连接或让房主重新同步项目。

为什么不能编辑某个角色

该角色已被其他成员认领，或房主锁定了全部代码。可以发送编辑申请，等待对方释放。
