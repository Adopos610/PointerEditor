指针迭代实验室 · 章程与规划

这份章程说明我们是谁、为什么做这些项目、如何治理、赞助会用在哪里，以及未来一段时间准备做什么。

v1.0 草案

本章程会随着实验室的发展调整。欢迎在 GitHub Issues 提出建议。

我们是谁

指针迭代实验室是一个独立的中文创作工具与云服务项目组，目前由维护者个人主导开发和运营。我们基于 Scratch 生态做更顺手的编辑器、协作服务和 AI 创作能力，也维护创客次元、指向云盘等周边项目。

使命

让中文创作者用更顺手的工具，把脑子里的想法真正做出来。

我们不追求把界面做得像花束一样好看，而是希望它像一把称手的工具：能敲、能用、能陪你把作品做完。

四条原则

1. 真实可用优先

真实积木、真实画板、真实运行引擎。功能先保证能用，再谈包装；不用假按钮和空壳页面充数。

2. 开放与透明

PointerEditor 以 GPL-3.0 开源，源码、Issue、版本记录和发布产物公开在 GitHub。服务端不会把用户密钥、数据库或私密配置带进仓库。

3. 协作优先

除了让 AI 帮你写，我们更在意让一群人真的能一起做：同房间认领角色、代码锁定、编辑申请、TODO 同步和多窗口拖素材，都是围绕这个目标做的。

4. 长期主义与克制

不堆无意义的功能，不靠夸张承诺换增长。每个新功能都要回答：它是否让创作更顺、让协作更真实、让维护成本可控。

项目治理

  • 核心项目由维护者负责方向、发布和线上服务；开源仓库接受 Issue、Pull Request 和建议。
  • 版本号按语义化大致管理：小更新递增补丁号，重要功能递增次版本号。
  • 涉及用户数据的功能遵循最小必要原则：只收集完成功能所需的信息。
  • 线上服务、管理入口和用户数据库独立于公开源码；不公开账号密码、SMTP 授权码、API Key 或用户作品。

赞助与资金

实验室目前主要靠维护者个人承担成本。AI API、服务器、域名、构建与签名等都需要持续支出，因此我们在爱发电接受自愿赞助：

爱发电 · HUGOR

  • 赞助用于支付 API、服务器、域名、存储和发布相关成本。
  • 赞助是自愿支持，不购买产品特权，也不改变开源许可证。
  • 实验室会尽量公开资金的大致用途；具体账单和第三方账号信息不公开。
  • 如果未来资金有结余，会优先投入长期基础设施和文档建设。

社区约定

  • 尊重其他创作者，不发布违法、侵权、恶意或骚扰内容。
  • 不要滥用协作服务、AI API、验证码或邮件服务，不要尝试攻击、扫描或绕过限制。
  • 不要把自己的 API Key、账号密码或他人隐私提交到公开仓库、Issue 或作品里。
  • 发现安全问题时，请私下联系维护者，不要在公开 Issue 中贴出可直接利用的细节。
