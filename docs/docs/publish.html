发布作品与桌面版

这一页说明如何把作品发布到创客次元，以及 Windows 桌面版的文件关联、数据目录、多窗口和安装注意事项。

发布到创客次元

  1. 在桌面版打开作品，点击“云端 → 发布到创客次元”。
  2. 选择账号登录或 API Key 登录。
  3. 账号登录需要创客次元用户名/邮箱、密码和图中验证码；验证码不区分大小写。
  4. API Key 登录请粘贴以 fk_live_ 开头的 Key。
  5. 填写作品标题、简介、分类，选择是否允许下载，封面默认截取舞台画面。
  6. 发布成功后会得到作品短链接，可以复制或直接打开。
发布目前仅桌面版可用

创客次元接口未对浏览器跨域 POST 放行，网页版直接发布会失败。网页版可以正常创作和保存 .sb3，但发布请使用 Windows 桌面版。

Windows 文件关联

  • 安装版会注册 .sb3、.sb2、.sb，双击作品即可打开。
  • 程序已运行时，双击另一个作品会在现有窗口打开。
  • 文件 → 从电脑中打开（Ctrl+O）。
  • 文件 → 保存到原文件（Ctrl+S）；另存为（Ctrl+Shift+S）。
  • 保存只允许写回本次打开或另存为选择的路径，避免任意文件写入。

数据目录

目录内容
PointerEditorData界面状态、缓存、崩溃日志和本机配置
PointerEditorExports导出的作品、截图和其他文件

安装版和免安装版都把数据放在程序目录，便于整套拷贝和迁移；卸载时请确认是否需要保留这些目录。

多窗口

文件 → 新建窗口最多同时打开 8 个编辑器窗口。适合一边看教程、一边做作品，或同时处理多个项目。角色卡片右上角 ↗ 可以把角色直接拖到另一个窗口。

安装与更新

  • 新版从 GitHub Releases 下载。
  • 当前安装器未进行代码签名，Windows 可能提示“未知发布者”；请确认下载来源后选择“仍要运行”。
  • 覆盖安装一般会保留程序目录中的项目数据；重要作品仍建议单独导出 .sb3。

网页版与桌面版怎么选

  • 需要文件关联、保存到原文件、PEAgent 本地 API Key、发布作品：使用 Windows 桌面版。
  • 临时体验、跨设备使用、不想安装：使用网页版。
  • 需要把项目带走：桌面版直接拷贝数据目录，或导出 .sb3。
