编辑器基础

PointerEditor 复用真实的 Scratch 运行时和积木系统。熟悉 Scratch 的话可以几乎无缝上手；第一次使用的话，先记住五个区域就够了。

界面区域

区域作用
顶部菜单文件、设置、云端、PEAgent、TODO、编辑、插件、高级
积木分类与工作区左侧选择分类，中间拖拽拼接积木
舞台运行和预览作品；绿旗开始、红点停止
角色区添加、选择、复制、导出角色，右上角 ↗ 可拖到另一个窗口
造型 / 声音 / 背包编辑角色素材，保存跨作品复用的积木和素材

积木基础

  • 运动 / 外观 / 声音：角色移动、说话、换造型、播放音频。
  • 事件：绿旗、按键、点击、广播、克隆体启动。
  • 控制：等待、重复、条件、克隆与停止。
  • 侦测 / 运算：碰撞、距离、计时器、随机数、字符串与数学。
  • 变量 / 列表：保存分数、生命、背包数据等。
  • 自制积木：把重复逻辑封装成自己的积木，支持“运行时不刷新屏幕”。
变量和广播

变量是作品内的数据；广播用于角色和舞台之间发消息。PEAgent 也可以帮你创建变量、广播并插入对应积木。

造型和声音

  • 在“造型”页使用矢量画板绘制、调整图层、填充和变形，也可以导入图片。
  • 在“声音”页导入音频、裁剪、调整音量或直接录音。
  • 舞台背景和角色造型都支持复制、排序和删除。

保存与作品格式

  • PointerEditor 使用 Scratch 兼容的 .sb3 作品格式。
  • 桌面安装版支持保存到原文件（Ctrl+S）和另存为（Ctrl+Shift+S）。
  • 网页版通过下载保存 .sb3；请定期保存，避免浏览器数据被清理。
  • 打开 .sb2 / .sb 后，另存会转换为 .sb3。

快捷键

快捷键功能
Ctrl+O从电脑中打开作品
Ctrl+S保存到原文件；免安装/网页版会打开保存流程
Ctrl+Shift+S另存为
Ctrl+Z / Ctrl+Y撤销 / 重做
Ctrl+F在积木区查找积木

多窗口与跨窗口素材

在“文件 → 新建窗口”可以同时打开多个编辑器窗口。角色卡片右上角的 ↗ 可以直接拖到另一个窗口，把角色连同造型、声音和积木一起带过去。

需要 AI 帮忙写积木时，继续看 PEAgent 使用指南；需要和朋友协作时，看 协作与云服务。
